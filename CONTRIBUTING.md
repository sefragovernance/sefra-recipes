# Contributing

Issues are welcome: a pack that does not match what the vendor's API does today, a rule that is unclear, or a system you would like a pack for.

Pull requests are welcome for corrections to existing packs. A new pack is published only after its live check has passed against the vendor's sandbox, which we run ourselves, so please open an issue before writing one.

By sending a contribution you agree that it is licensed under Apache-2.0, as section 5 of the [licence](LICENSE) says. Never put a credential in a pull request: packs read every secret from Sefra's secret manager.
