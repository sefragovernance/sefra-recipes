# Security

## Reporting a problem

If you find a security problem in a recipe, or in Sefra itself, write to **security@sefra.io**, or use [private vulnerability reporting](https://github.com/sefragovernance/sefra-recipes/security/advisories/new) on this repository. Please do not open a public issue.

Tell us what you found, how to reproduce it, and which pack it affects. We reply as soon as we can and keep you informed until it is fixed. More on how we handle reports: <https://sefra.io/security>.

## What counts

- A rule in a pack that lets an agent do more than its README says.
- A default that is weaker than the README states.
- A credential, token or personal data committed to this repository.

A pack's thresholds are meant to be edited. A threshold you would set differently is not a vulnerability; open an issue instead.
